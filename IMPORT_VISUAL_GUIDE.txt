═══════════════════════════════════════════════════════════════════════════════
                        VALIDATION ERROR EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

❌ "File is too large"
   → Your file is >10MB. Split into smaller files.

❌ "Please upload a .csv or .json file"
   → You selected wrong file type. Choose .csv or .json only.

❌ "Could not identify CSV format"
   → CSV headers don't have Date, Description, Amount.
   → Solution: Check your CSV structure.

❌ "Invalid JSON format: Unexpected token"
   → JSON syntax error. Check for missing commas, quotes, brackets.
   → Validate JSON at jsonlint.com

❌ "No valid transactions found"
   → No rows passed validation. Check:
      • Date format is YYYY-MM-DD or MM/DD/YYYY
      • Amount is a valid number
      • Has date, source (description), and amount
