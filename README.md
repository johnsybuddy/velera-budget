# Bills Q Tracker

A family budget tracking website built with HTML, CSS, and JavaScript.

## GitHub Pages Setup Instructions

1. **Create Repository**:
   - Go to GitHub.com and create a new repository
   - Name it `bills-website` (or any name you prefer)
   - Make it **Public** (required for free GitHub Pages)
   - Don't initialize with README (we already have files)

2. **Upload Files**:
   - Click "uploading an existing file"
   - Drag and drop these files:
     - `index.html`
     - `styles.css`
     - `script.js`
     - `README.md`

3. **Enable GitHub Pages**:
   - Go to repository Settings
   - Scroll to "Pages" section
   - Source: Deploy from a branch
   - Branch: `main` (or `master`)
   - Folder: `/ (root)`
   - Click Save

4. **Access Your Website**:
   - Your site will be available at: `https://yourusername.github.io/bills-website`
   - It may take a few minutes to deploy

## For Your Wife to Edit

1. **Give Access**: Add her as a collaborator in repository Settings > Collaborators
2. **Easy Editing**: She can edit files directly on GitHub.com by clicking the pencil icon
3. **No Technical Knowledge Needed**: GitHub's web interface is user-friendly

## Files Structure

- `index.html` - Main website file
- `styles.css` - Styling and layout
- `script.js` - Interactive functionality
- `README.md` - This documentation

## Future Migration to AWS

When ready to scale, simply copy these same files to AWS S3 - no code changes needed!
